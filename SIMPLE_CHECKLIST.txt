├──────────────────────────────────────────────────────────────┤
│                                                              │
│  On Render:                                                  │
│  ├─ Go to your website service                               │
│  ├─ Settings → Custom Domain                                 │
│  ├─ Add: yourcompany.com (or .tk)                            │
│  └─ Copy DNS records shown                                   │
│                                                              │

│  ├─ Add A Record: @ → (IP from Render)                       │
