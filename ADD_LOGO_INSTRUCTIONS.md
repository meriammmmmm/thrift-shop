# How to Add the Mery Rose Logo

## Step 1: Save the Logo Image
1. Save your Mery Rose logo image (the one with the elegant woman silhouette and rose)
2. Name it: `mery-rose-logo.png`
3. Place it in: `thrift-shop/public/images/mery-rose-logo.png`

## Step 2: Logo is Already Integrated!
The website code has been updated to automatically use your logo. Once you add the image file, it will appear in:
- The header/navigation bar
- Centered and elegant
- With smooth hover animations
- Fallback to text if image doesn't load

## Quick Test:
1. Add the logo image to the path above
