🚀 Deployment Strategy

Each company gets:

  • Their own domain (vintagetreasures.com, ecofashionhub.com, etc.)
  • Their own server instance with COMPANY_ID environment variable
  • Same codebase deployed with different configuration
  • Isolated data (filtered by company_id in database)
  • Separate admin panel access
  • Own customer base
