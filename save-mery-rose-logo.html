📋 How to Add Your Logo

Step 1: Right-click on your logo image (the pink one with the woman and "Mery Rose" text)
Step 2: Select "Save Image As..." or "Download Image"
Step 3: Save it with this exact name:
mery-rose-logo.png
Step 4: Move the file to this location:
thrift-shop/public/images/mery-rose-logo.png
Step 5: That's it! The logo will automatically appear on your website! 🎉
⚠️ Important: Make sure the file is named exactly mery-rose-logo.png and placed in the thrift-shop/public/images/ folder.

🚀 Alternative Method (Drag & Drop)

Option 1: Open your file explorer/finder
Option 2: Navigate to:
thrift-shop/public/images/
Option 3: Drag your logo image directly into that folder
Option 4: Rename it to: mery-rose-logo.png

✨ What Happens Next?

Once you add the logo:

  • It will appear in the center of the navigation bar
  • It will have a beautiful floating animation
  • It will glow on hover
  • It will be responsive on all devices
  • If it fails to load, it will show "MERY ROSE" text instead
